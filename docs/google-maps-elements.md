# Google マップの要素分解（徒歩）

2026-11-02 に Google マップの地図・施設・徒歩経路・ジャンル検索の 4 画面の操作部品を取得し、
徒歩で使う部分を要素に分けた。上から順に実装する。

印: ✅ 実装済み ／ 🟡 一部 ／ ⬜ 未実装 ／ — 対象外

## 1. 経路の正しさ

| 要素 | 状態 |
| --- | --- |
| 歩ける道だけを通る（高速・有料道路を除く） | ✅ |
| 登山道を通らない | ⬜ |
| 夜の山道を出さない | ⬜ |
| 市境の外の道も経由できる | ⬜ |
| 道の途中の地点へ案内する（交差点へ寄せない） | ⬜ |
| 長距離・大きな上りの注意 | ⬜ |
| データのない道は安全度を「不明」にする | ⬜ |

## 2. 地図の表示

| 要素 | 状態 |
| --- | --- |
| 移動・拡大縮小 | ✅ |
| 日本語の地図文字 | ✅ |
| 縮尺 | ✅ |
| 回転・傾き・方位の復帰 | 🟡 |
| 現在地の青い点と精度の円 | 🟡 |
| 地図の種類の切り替え（航空写真・地形） | ⬜ |

## 3. 検索

| 要素 | 状態 |
| --- | --- |
| 名前・読み・住所の検索と候補 | ✅ |
| ジャンル検索（コンビニ等）と結果一覧 | ⬜ |
| ジャンルのボタン | ⬜ |
| 地図の範囲で探し直す | ⬜ |
| 最近の検索 | ⬜ |

## 4. 場所の情報

| 要素 | 状態 |
| --- | --- |
| 名前と種別 | ✅ |
| 住所・営業時間・電話・ウェブサイト | ⬜ |
| 地図上の施設を押して開く | 🟡 |
| 長押しで地点を選ぶ | ⬜ |
| 付近を検索 | ⬜ |
| 共有 | 🟡 |

## 5. 徒歩の経路画面

| 要素 | 状態 |
| --- | --- |
| 出発地・目的地・入れ替え | ✅ |
| 複数の経路と所要時間・距離 | ✅ |
| 「〜経由」の表示 | ⬜ |
| 曲がる場所の案内 | ✅ |
| 高度プロファイル | ⬜ |
| 目的地の追加（経由地） | ⬜ |
| 経路沿いの検索 | ⬜ |
| リンクのコピー | ✅ |

## 6. 歩きながらの案内

| 要素 | 状態 |
| --- | --- |
| 現在地の追従と次の曲がり角 | ✅ |
| 外れた時の探し直し | ✅ |
| 進行方向の表示 | ⬜ |
| 音声案内 | ⬜ |
| 画面を消さない | ⬜ |

## 7. 画面全般

| 要素 | 状態 |
| --- | --- |
| 戻る・進む・URL の復元 | ✅ |
| スマートフォンの引き出せるシート | ⬜ |
| 読み込み中の表示 | ⬜ |

## 対象外

車・電車・自転車・飛行機の経路、渋滞、ストリートビュー、クチコミ、店の写真、
ログイン・保存、スマートフォンへの送信。SafeWalk は徒歩のみで、これらのデータも持たない。
