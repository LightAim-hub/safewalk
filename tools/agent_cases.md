# Claude 組み込みの確認用の質問 20 件

鍵を入れて deploy した後に、画面（または `runAgent`）へ下の質問を入れて確かめる。
鍵なしでは `node worker/test/agent_mock_test.mjs` と `node worker/test/relay_test.mjs`（worker フォルダで実行）が、仕組み（照合・差し替え・回数制限）を確かめる。
ここにある物は、実際の Claude の答え方を人の目で確かめるためのもの。

## 全件に共通の合格条件

- 答えに「安全」「安心」「危険」「治安」「犯罪」「保証」「絶対」「%」「パーセント」が出ない（画面の固定の免責文を除く）。
- 数字（距離・分・件数・軒数）は、同じ画面の経路の一覧・記録と一致する。一覧に無い数字を言わない。
- 経路は「経路A・経路B」と呼び、「最も安全」と呼ばない。
- 注意書きは `safety.ts` の固定の文がそのまま出る。言い換えがない。
- 各理由に根拠（元の記録の文）が開ける。根拠の無い理由は出ない。
- 免責「交通事故の記録に基づく目安。安全を保証しません」が出る。
- 差し替えが起きた時（`replaced` に記録が入る）は、固定の文で表示され、画面が壊れない。

## 見る点の補足

- 6・7・13 は禁止語の照合が働く典型。Claude が禁止語を出した場合は、画面にはその文が出ず、固定の文に変わっていること（`replaced` に記録が残る）を見る。
- 8・16 は数字の照合。一覧に無い数字を出した文は画面に出ないこと。
- 10 は市外。経路が無いので `ok: false`、経路を出さない。
- 回数の上限（1 IP 10 分に 20 回・24 時間に 60 回、全体で 1 日 1000 回）に当たったら、日本語の文が出て、経路の検索は Claude なしで使えること。
